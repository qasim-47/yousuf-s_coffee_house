
# ☕ Yousuf's Coffee House

A full-stack Coffee Shop Web Application developed using PHP, MySQL, HTML, CSS and JavaScript.

## About the Project

Yousuf's Coffee House is a web-based coffee shop application where customers can explore the menu, create accounts, add products to their cart and place orders.

The application also includes an Admin Panel to manage customer orders.

## Features

### Customer Features
- Customer Signup and Login
- Browse Coffee Menu
- Add to Cart
- Checkout
- Place Orders

### Admin Features
- Admin Login
- Admin Panel
- View Customer Orders
- View Order Details
- Update Order Status

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Run Locally

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside `htdocs`.
4. Create a MySQL database named `coffe_shop`.
5. Configure your local `db.php` database connection.
6. Import your database backup/schema into phpMyAdmin.
7. Open this URL in your browser:

   http://localhost/CoffeShop/index.php
